# 🩻 Layout X-Ray: the "Outline Debug" technique

A zero-impact way to *see* your UI's layout boxes while debugging alignment, padding, overlaps, and heights — without changing the layout at all.

## The idea
Overlay colored outlines on elements so you can **see the invisible boxes** (rows, labels, inputs, toggles) and spot geometry problems at a glance.

## The CSS (copy-paste)
```css
/* outline each container (row/card/item) */
.panel .row {
  outline: 1px dashed rgba(224, 85, 106, .7) !important;   /* dashed = group */
  outline-offset: -1px;
}
/* outline each child (label / control / etc.) */
.panel .row > * {
  outline: 1px solid rgba(91, 141, 239, .5) !important;    /* solid = element */
}
```

## Why `outline` instead of `border`?
- `border` **adds to the box size** → it *moves* the layout (everything shifts a few px) ❌
- `outline` is drawn **on top, takes zero space** → the UI stays pixel-identical, you just see the boxes ✅

## How to use it
1. Inject the CSS (devtools stylesheet, a `<style>` tag, or a bookmarklet)
2. Toggle it on/off as you inspect
3. Use **two colors/roles**:
   - **Group outline** (dashed) → rows, cards, sections
   - **Child outline** (solid) → labels, inputs, toggles, buttons
4. Mix in more colors for special cases:
   ```css
   /* find overlaps: color each child differently */
   .panel .row > *:nth-child(1) { outline-color: #e0556a; }
   .panel .row > *:nth-child(2) { outline-color: #5b8def; }
   .panel .row > *:nth-child(3) { outline-color: #4caf84; }
   ```

## What to look for
- **A box taller than its text** → wrapping, crush, or a bad `min-height`
- **Overlapping boxes** → collisions (two outlines crossing = text/control overlap)
- **Uneven row heights** → inconsistent padding/line-height
- **Empty space inside a control** (e.g., big gap before a dropdown arrow) → oversized `min-width`/padding
- **Vertical misalignment** → child boxes not centered in their row box

## As a bookmarklet (one-liner)
```js
javascript:(()=>{const s=document.getElementById('layout-xray');if(s){s.remove();return}const t=document.createElement('style');t.id='layout-xray';t.textContent='.row,.card,.setting-row,.item{outline:1px dashed rgba(224,85,106,.7)!important;outline-offset:-1px}.row>*,.card>*{outline:1px solid rgba(91,141,239,.5)!important}';document.head.appendChild(t)})()
```
Click it once → x-ray on. Click again → off.

## Rules of thumb
- Always `!important` (so it wins over the app's styles)
- `outline-offset:-1px` keeps lines snug inside the box
- Semi-transparent colors (`rgba`) let the content show through
- It's **debug-only** — remove before shipping (zero user-facing value)
