# Web-API Poking — clue sheet (field-tested, Sept 2026)

High-density notes from ~50 tool calls reverse-engineering an obfuscated SPA + hidden API.
Use as a pattern library; adapt names/URLs per target.

---

## 0. First moves (cheap wins)

- Check `/llms.txt`, `robots.txt`, sitemap, JSON-LD blocks, `__NEXT_DATA__`, RSC payloads.
  Sites increasingly self-document for agents; JSON-LD `ItemList` often lists "current" state.
- Grab every `<script src>` / `<link>` from the HTML — that's your map to the code.
- Look at error pages: Symfony/PHP style ("An Error Occurred") tells you the stack AND
  that a WAF/CDN in front enforces methods before the app.

## 1. Obfuscated JS → strings → API

- obfuscator.io pattern: file starts `var X=DECODER; function TABLE(){return [ ...strings... ]}`
  and code calls `DECODER(0xNNN)`. The raw array is ALSO visible as plain text in the file.
- To read strings: `(0,eval)(wholeFile)` **inside a Worker (no DOM)** → decoder becomes
  callable (`globalThis[decoderName](hex)`). Eval whole file so the rotate-IIFE runs.
- Decoder name = 2nd identifier on line 1: `^var\s+\w+\s*=\s*(\w+)\s*;`
- Filter decoded strings for `/`, `http`, `.com`, `api` → endpoint list.
- Webpack lazy chunks: `js/<name>.<hash>.js`; `<hash>` often == app hash; find chunk names
  by regexing main bundle for `([A-Za-z0-9_]+_vue)` or the chunk-map literal.

## 2. Signing (the usual scheme)

- `sign = MD5(sortedQueryString + SECRET)`, hex lowercase.
  sortedQueryString: keys sorted, `k=v&k2=v2`, values `encodeURIComponent` (objects JSON).
- SECRET is in the bundle (it must be). If it's the MD5 suffix, locate its index with:
  `\[['"]MD5['"]\]\)\([^)]*\+[A-Za-z_$][\w$]*\((0x[0-9a-f]+)\)`  → decode that hex index.
- Always verify your MD5 impl: `md5('abc')==='900150983cd24fb0d6963f7d28e17f72'`.
- Server's sign-failure response (e.g. `err_code:0` + "Sign Error") = your trigger to re-extract.

## 3. CORS / reaching endpoints from a browser

- urlencoded POST & GET = CORS **simple** → readable if server sends `ACAO:*`.
  Custom headers / `application/json` → preflight OPTIONS → often blocked.
- **"Failed to fetch" ≠ dead endpoint.** Often the server answered with an error page that
  lacks ACAO. Check with `mode:'no-cors'` (server responded?) then use a relay to read it.
- Relays (all public, CORS-enabled):
  - `get2post.vercel.app/api/post?url=<T>&method=GET&response=json` — GET proxy.
    Default method is POST; `&data=<raw>&headers=<json>` forwards body + custom headers.
    Returns `{status,headers,body}`; upstream status inside. Logs requests (redacts
    Authorization/sign/keys). ~1MiB cap. Some bot-protected origins → 403 (Century static
    site did; Century API did NOT).
  - `allorigins.hexlet.app/raw?url=` and `cors-tube.vercel.app/?url=` — GET only, reliable.
    Most other public proxies hung/failed — don't waste retries.
  - `r.jina.ai/<url>` — GET text-reader fallback.
- **Next.js Server Actions**: POST to the page URL with header `Next-Action:<actionId>`,
  body `["arg"]`, `Content-Type: text/plain;charset=UTF-8`, `Origin:<same-site>`.
  Cross-origin direct calls get CSRF-blocked; relaying through get2post with the Origin
  header set works. Response = React Flight lines; the line containing `"status"`+`"data"`
  is JSON (often has the answer).
- `X-HTTP-Method-Override` / `_method=POST` GET tricks → **405 at WAF**, skip.

## 4. Probing & semantics (do this before acting)

- Send invalid/neutral inputs first; map the server's error-code vocabulary
  (notfound / expired / used-up / already-claimed / dup-type / rate-limited / sign-fail).
  Each code is ground truth → you can "classify" resources without side effects.
- Rate limits are real & silent (~10/min). Pace ≥4s, on rate-code wait 60s once.
  Watch `x-ratelimit-*` response headers for the actual cap.
- Correlated fields get validated (e.g. player-id + server-id): mismatch returns a
  specific code — that tells you which fields the server actually checks.

## 5. Scripting/loading gotchas

- `fetch(u).then(r=>r.text()).then(eval)` → top-level **function** decls become global,
  **const/let do NOT**. Always end the file with `globalThis.KSR = {...}` and use that.
- `raw.githubusercontent.com` = `ACAO:*` (fetch+eval OK) but MIME `text/plain`
  → `<script src>` blocked. GitHub Pages serves JS MIME → script tag OK.
- Persist state by opaque IDs (`localStorage`), config without names/PII, cache derived
  lookups, auto-retry on sign-failure by re-extracting the secret.

## 6. Case: Kingshot gift codes (worked example)

- Site `ks-giftcode.centurygame.com` (Vue SPA, obfuscated).
- Real API: `https://kingshot-giftcode.centurygame.com/api`
  - `POST /gift_code` (urlencoded, signed) — redeem. **Captcha NOT enforced.**
  - `POST /gift_code_config` — UI config only (no code list).
  - `/player`, `/captcha` — 404/blocked, dead ends.
- Verdicts (err_code): `20000` SUCCESS · `40005` USED UP · `40007` TIME/expired ·
  `40008` already RECEIVED · `40011` SAME TYPE used · `40014` NOT FOUND ·
  `40019` TOO FREQUENT · `40020` USER INFO ERR (fid/kid mismatch) · `0` Sign Error.
- Kingdom id (`kid`) IS validated against player id → need lookup, can't skip.
- Lookup: official `/player` dead → fan site `kingshot.net` Next.js Server Action
  (`Next-Action: 40a98b52a0796b9ad015ccc308355704ea2b8155c4`) → returns player JSON
  incl. `kingdom`. Relay via get2post with `Origin: https://kingshot.net`.
- Secret was `mN4!pQs6JrYwV9` (chunk idx `0x1b4`); script re-extracts if rotated.
- Live-code finder = probe candidates (`KS+MMDD`, `OFFICIALSTORE+MMDD`, community
  JSON-LD list) on one account; verdict classifies live/expired/fake instantly.
